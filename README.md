# my-Language-notebook
# AI语言学习笔记本

## 项目简介
这是一个用 Vibe Coding 模式快速开发的 AI 语言学习工具原型。用户输入学习笔记，AI 自动生成口语练习卡片、闪记卡，并提供对话模拟功能。

## 核心功能
- 智能提取笔记中的场景和关键词
- 生成可翻转的闪记卡（单词+释义）
- 模拟真实场景的口语对话练习

## 技术栈
- HTML/CSS/JavaScript
- 大模型 API（预留接口）
- Vibe Coding（Cursor + AI辅助开发）
